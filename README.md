# ATELIER — Fashion Store Starter

Энэ бол Visual Studio Code дээр шууд нээж ажиллуулах static e-commerce starter.

## 1. Шаардлагатай зүйл
- Visual Studio Code
- Chrome / Edge

## 2. Ажиллуулах
1. Энэ folder-ийг VS Code-оор нээнэ.
2. `index.html` дээр right click → Open with Live Server (Live Server extension суулгана).
3. Эсвэл `index.html` файлыг browser дээр шууд нээж болно.

## 3. Файлууд
- `index.html` — website-ийн бүтэц
- `style.css` — дизайн, responsive layout
- `script.js` — бүтээгдэхүүн, tab, search, cart-ийн demo ажиллагаа

## 4. Дараагийн шат
Эхлээд энэ front-end-ийг өөрийн брэндийн нэр, зураг, өнгө, бүтээгдэхүүнээр солино. Дараа нь backend, database, QPay/card payment, delivery, admin dashboard холбоно.
